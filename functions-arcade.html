Functions Arcade

A collaborative collection of small games built for a class arcade. My contribution is a five-round coin-flip game where players score points for correct guesses.

FUNCTIONSARCADE✦   ●   ▲

About the project

The arcade brings together student-created games behind one menu. My coin game uses Python's random module to flip heads or tails, compare the result with a player's guess, and keep a score over five rounds.

What I practiced

  • Using functions to organize a small game.
  • Generating random outcomes and checking user input.
  • Tracking and displaying a score across multiple rounds.
  • Contributing code to a shared project.
